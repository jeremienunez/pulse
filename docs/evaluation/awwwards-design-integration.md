## Deterministic verification

[The test suite](../../scripts/test-design-verbatim.mjs) verifies source identities against the independently pinned approved-map digest, exact MIT licence, unique source matrix, one-level destinations, current output bytes and inverse operation reconstruction. It exercises deleted sections, changed numeric prescriptions, lost exceptions, missing destinations, duplicate/unknown operation metadata and attempted source-map repinning. A synthetic declared numeric change intentionally demonstrates the boundary: byte reconstruction can pass while semantic approval is still required. These fixtures are not actual candidate changes or behavioural model results.

The same verifier runs on a distribution extracted outside the checkout, without the upstream clone, provider, browser or new dependency. It is included in the existing package CI suite. Targeted guide links and fresh capture destinations are checked; link presence is not a proof that an agent used the text. Licence and source data travel with the package, while upstream helpers, history and local profiles remain external.

During development, the first test run exposed the controller's missing `coverage` category for the already-declared authenticated-review adaptation. The allowed category set was corrected and the targeted ten conservation/package tests passed. Final combined checks and review outcomes are recorded in the run's execution/review artefacts; they must not be inferred from this protocol description.
