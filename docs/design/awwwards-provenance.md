## Retention and adaptation

[The source lock](../../skills/design/references/awwwards-source-lock.json) records all 19 text sources and their destination/byte identities. The generated awwwards quality-bar differs only by its generated header and shares the complete canonical jury reference. Eighteen destinations retain concept, art direction, typography, layout, content, motion, patterns, quality, scoring, anatomy, shipping and the optional engine/WebGL/Next/Astro recipes. Both master skills' distinct hard rules and methods are retained.

[The exact operation ledger](../../skills/design/references/awwwards-adaptations.json) records byte positions, original/replacement text, reasons and approved arbitration IDs. Inverting it reconstructs each pinned source, including the generated alias header. This detects undeclared changes; it does not decide whether a declared rewrite preserves meaning. Substantive review of each final destination and exact diff remains required.

[Local notes](../../skills/design/references/awwwards-adaptation.md) address the selected expressive scope, concept choice, Pulse artefacts, critic independence, scores/gates, historical calibration, quotas, strong opinions, helpers, access, specific recipe discordances and examples. Examples, numbers, code and their exceptions remain the main material; these notes do not replace them with a summary.

## Tools and evidence

The helper identities remain in the lock as external source. Their presence in a recipe does not establish installation or execution. A verified upstream checkout and approved local preparation are needed to invoke them. The module is not a second build, QA or delivery runtime. Framework and rendering code remains optional reference text for the selected project stack.

The historical +1.1 calibration remains complete with its two cases, limitations and old reporting bug. It is not automatically applied to Pulse or another reviewer. Upstream site observations and tests remain attributed to that snapshot. Code examples are not locally qualified by copying them.

## Local acceptance boundary

This cycle explicitly selected a human-reviewed source proposal at Gate 3. [Evaluation](../evaluation/awwwards-design-integration.md) records frozen cases, text preservation, exact adaptation review, package checks and remaining behavioural limits. Behavioural baseline/retest are not executed, immutable executed model version is unavailable and automatic promotion remains false. Source adoption, installation, commit and push retain their own authorisation.
