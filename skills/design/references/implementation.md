# Realize the approved direction

Read the approved brief, current graph node and the surrounding interface. Translate the selected intention into working content and interactions inside that scope. These methods complement the existing execution contract.

## Compose from the task

Name what leads, what supports it, what belongs together and the reading or task path. Use proximity and deliberate spacing to express these relationships. Repeated content may share a pattern; give different priorities different weight. The framework's default containers need not decide the composition.

Carry the approved reference transformation into those relationships, rather than copying a motif. Preserve established tokens, type roles and shared components when extending a system. Adjust a local defect at its owning level. Replacing the identity or changing approved content goes through the existing Pulse revision path.

Carry the accepted branches and outcomes of the [cultural research](cultural-digging.md) into an open expressive direction's transformations. Its trace stays in the existing task research; realization does not create a second tree. Use [motion](motion.md) when the approved interaction or temporal composition needs it.

Make typography express roles through size, weight, spacing and tone. Tune reading density to the actual content, face and surface; inspect long text and fallback fonts. Use color to communicate hierarchy, state or identity. Assess readability against the project's accessibility target, not a palette's attractiveness.

## Complete the material states

Use the brief's real or clearly illustrative content. Controls name their actions. For a task flow, realize its relevant loading, empty, error and success states. An error explains recovery; preserve valid input when the flow requires retry. Inspect the states that the changed behavior actually introduces.

Adapt composition when space or input method changes: reflow, reorder or simplify while retaining essential content/actions and coherent DOM/focus order. Check overflow and text expansion with the project's supported sizes. A narrow capture establishes layout evidence; gestures require interaction evidence.

Motion can explain feedback, state or continuity when this surface benefits. Keep the information and control path usable with reduced motion. Add effects only when they serve the accepted direction and fit the project's performance budget.

## Inspect the result

Use the project's existing rendering and verification tools. Batch relevant sizes/states in one inspection, compare them to the brief, and repair concrete defects within scope. Reinspect the affected result. Preserve captures, measured viewport dimensions and interaction observations under the current node's verification directory. Report an unavailable check as unobserved. A successful build supplies build evidence; visual fit and working interactions each need their own support.
