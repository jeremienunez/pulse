# Shared-instinct compounding boundary

Compounding remains the canonical post-cycle learning pass for Pulse projects.
The shared-instinct controller may reference its verified outcome under the
same candidate identity, but compounding does not publish an active instinct.

This change prevents two durable writers from silently promoting contradictory
behavioural rules. The boundary is verified through controller fixture tests;
installed runtime integration remains separately pending.
